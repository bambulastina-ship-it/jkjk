## Uploading photos

Drop everything into **`assets/images/`**.

**Filenames do not matter.** Upload them however they come off your phone — `IMG_2043.jpg`,
`WhatsApp Image....jpeg`, anything. I will look at each one and wire it to the right place
on the page.

It helps if you mention which is which when you tell me they're up, e.g.
"the logo is the square one, the owner is IMG_2043".

What's most useful, roughly in order:
1. **Logo** — transparent PNG at 600px or larger, or an SVG. *(Small logos go blurry when
   used big — the last client's was 150px and could not be used in the hero.)*
2. **A wide shot of the gym floor** — this becomes the main hero image
3. **Owner / gym master portrait**
4. **Equipment, workouts, classes, trainers** — as many as you have
5. Before/after or progress photos, if you have any you're allowed to use

**To upload from the browser:** open [`assets/images`](../../upload/main/veera/assets/images),
drag the files in, then press *Commit changes*.

## Editing the text

Everything the page says lives in **`js/content.js`** — reviews, services, stats, address, hours.
Edit that one file; nothing else needs touching.

## Running it locally

No build step, no dependencies.

```bash
python3 -m http.server 8080
```
