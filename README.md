# Five UK business landing pages

Five independent, premium landing pages — one per business. Each is built
standalone: its own visual identity, layout, typography, colour direction and
motion. Not five skins of one template.

```

```

## Ground rules

- Landing pages only — no payment integration of any kind, no cart, no checkout.
- Mobile, tablet and desktop all treated as first-class.
- Copy stays factual: no invented reviews, awards, statistics or accreditations.
- Effects (ShaderGradient, Liquid Logo, Liquid Glass JS, React Three Fiber) are
  used per site only where they genuinely improve the design.
